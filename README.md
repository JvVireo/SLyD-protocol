# SLyD protocol
an protocol for find &amp; connect server with client by "domain"
it's automatically find the target server by his own "domain" - unique name for the servers that uses this protocol.
SLyD (Server Lookup by Domain) protocol is based on java's realization of TCP (Transmission Control Protocol), that is to say, on "Socket" classes.
I took the idea from the CLaJ (Copy Link and Join) mod, but instead of generated link, i make the domains, that owner of the server configures himself.
